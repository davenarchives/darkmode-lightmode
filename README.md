# Dark Mode / Light Mode Toggle

This project provides a simple implementation of a dark mode/light mode toggle button using HTML, CSS, and JavaScript. The toggle button uses smooth transitions and emojis for a modern and engaging user experience.

## Features
- A minimalist toggle button with emoji indicators: 🌞 for light mode and 🌙 for dark mode.
- Smooth transitions between themes for background and text color.
- Responsive and accessible design with a clean UI.

## How It Works
1. **HTML Structure:**
   - The toggle button is defined in HTML and starts with the moon emoji 🌙 to indicate light mode.
   - A `div` container holds the button and content for easy styling and layout.

2. **CSS Styling:**
   - Default light mode styles are applied to the body.
   - Dark mode styles are defined and applied dynamically by toggling a `dark-mode` class.
   - Smooth transitions are used for seamless theme changes.

3. **JavaScript Functionality:**
   - The button toggles the `dark-mode` class on the body when clicked.
   - Emojis update dynamically to reflect the current theme.
